## Gorev

Kendi JSON parserini sifirdan yaz. Hazir kutuphane kullanma.

## Desteklenen tipler

- String
- Number (tamsayi ve ondalikli)
- Boolean (true/false)
- null
- Array
- Object

## Kurallar

- Recursive descent parser olmali
- Gecersiz input icin hata firlatmali
- Testleri calistir
